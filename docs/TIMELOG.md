# 实际用时记录

下面记录本次 AI 协作开发会话的工作阶段与关键判断。

| 阶段 | 用时 | 内容 |
|---|---:|---|
| PDF 检查与方案设计 | 约 0.5 小时 | 判断混合 PDF、识别表格类型和风险 |
| 核心实现 | 约 1.5 小时 | 解析、结构化、问答、自检 |
| 测试与修正 | 约 1.5 小时 | 单元测试、黄金集、实际 PDF 回归 |
| 文档与演示 | 约 0.5 小时 | README、设计说明、零依赖 Web 演示 |
| 合计 | 约 4 小时 | 解析、实现、验证和文档闭环 |

## 关键思考检查点

时间记录不仅统计编码量，也记录改变方案的判断：

| 检查点 | 观察 | 对实现的影响 |
| --- | --- | --- |
| 首次检查 PDF | 只有第 6 页是扫描页 | 从全量 OCR 改为逐页路由 |
| 首次文本抽取 | 表格数字存在，但行列语义丢失 | 从全文切块改为结构化单元格证据 |
| 首次 OCR 回归 | 出现非法数字格式和低置信度 | 增加 `needs_review` 与确定性检查 |
| 首次上传验证 | 上传成功不能证明知识库已切换 | 增加旧问题反向测试和失败回滚 |
| 最终回归 | 单看答案无法发现引用错误 | 黄金集同时检查状态、数值和页码 |
